## 1. 下載與第一次執行

1. 到 [Releases 頁面](https://github.com/Enostseng/ImeSwitcher/releases/latest)，下載 `ImeSwitcher.exe`。
2. 建議先把它放到固定的資料夾，例如 `C:\Tools\ImeSwitcher\`。如果之後要設定開機自動啟動，exe 就不能再搬動。
3. 雙擊 `ImeSwitcher.exe`。

### 跳出「Windows 已保護您的電腦」怎麼辦？

這個程式沒有購買數位簽章，所以 Windows SmartScreen 可能會擋下第一次執行：

1. 點視窗裡的 **其他資訊**。
2. 點 **仍要執行**。

只有第一次會出現。如果想確認下載的檔案沒被竄改，可以在 PowerShell 執行下面的指令，把結果和 Release 頁面公布的 SHA-256 對照：

```powershell
Get-FileHash .\ImeSwitcher.exe -Algorithm SHA256
```

### 執行之後

- 程式**沒有視窗**，會常駐在右下角的系統匣。
- 第一次執行時，右下角會跳出通知：「已在系統匣執行」。
- 如果看不到圖示，點系統匣的 **︿**（顯示隱藏的圖示），就能找到它。建議把它拖到工作列上，方便隨時查看狀態。

## 3. 功能一：切換微軟注音輸出繁體／簡體

適合**要用注音打一段簡體字**的時候，例如回覆大陸客戶、在淘寶搜尋商品。

**操作：** 按 `Alt + Shift + F`（或單擊系統匣圖示）。

1. 畫面上方會短暫顯示「簡體」或「繁體」。
2. 系統匣圖示跟著變色。
3. 直接用注音打字，就會輸出對應的字體。

**範例：** 輸入「ㄍㄨㄛˊ」，切換前出現「國」，切換後出現「国」。

> **小提醒：** 這個功能是修改「微軟注音」本身的「輸出簡體中文」設定，所以切到簡體後，**所有程式**打出來都會是簡體，用完記得切回來。如果切換後打字沒有變化，先按 `Win + Space` 切到別的輸入法再切回注音。

## 4. 功能二：選取文字直接轉繁體／簡體

適合**已經有一段文字**要整段轉換的時候，例如把對岸的商品文案轉成繁體。

**操作：**

1. 在任何程式裡（記事本、Word、瀏覽器輸入框、LINE 等）用滑鼠**選取**要轉換的文字。
2. 按快速鍵：
   - `Alt + Shift + T`：轉成**繁體**
   - `Alt + Shift + S`：轉成**簡體**
3. 選取的文字會直接被換掉，畫面上方會顯示「已轉成繁體（N 字）」。

**範例（預設模式）：**

| 選取的文字 | 按 `Alt+Shift+T` 之後 |
|---|---|
| 头发和后来 | 頭髮和後來 |
| 一只鸟在游戏 | 一隻鳥在遊戲 |
| 软件开发 | 軟件開發 |

**幾點說明：**
- 轉換時程式會借用剪貼簿，**轉完會把剪貼簿還原成原本的內容**，不會弄丟你剛複製的東西。
- 貼回去的是純文字，原本的粗體、顏色等格式會不見。
- 如果沒有選取任何文字，只會顯示「沒有選取文字」，什麼都不會改。
- 對「以系統管理員身分執行」的程式無效，這是 Windows 的安全限制。

## 5. 要不要改用台灣用語？

預設**只轉字形**，不改用詞。如果希望一併換成台灣慣用的說法，可以開啟「台灣用語」。

| 原文（簡體） | 預設：只轉字形 | 開啟台灣用語 |
|---|---|---|
| 软件开发 | 軟件開發 | 軟體開發 |
| 信息网络 | 信息網絡 | 資訊網路 |
| 数据库 | 數據庫 | 資料庫 |
| 头发 | 頭髮 | 頭髮 |

**開啟方式：** 右鍵系統匣圖示，勾選 **選取轉換時改用台灣用語**。再點一次就是關閉。

> 開啟後，繁轉簡也會反向換成大陸用語，例如 軟體→软件、資訊→信息。

轉換詞庫使用開源專案 [OpenCC](https://github.com/BYVoid/OpenCC)，是以詞為單位轉換，不是一字對一字，所以「头发→頭髮」「后来→後來」這類容易轉錯的字都能正確處理。

## 6. 開機自動啟動

1. 右鍵系統匣圖示。
2. 勾選 **開機自動啟動**。

之後每次開機都會自動在背景執行。

> 如果搬動了 exe 的位置，要**重新勾選一次**，因為 Windows 記錄的是 exe 的完整路徑。

## 7. 自訂快速鍵與其他設定

右鍵系統匣圖示 → **開啟設定檔**，會用記事本打開 `%APPDATA%\ImeSwitcher\settings.ini`：

```ini
[General]
Notify=1
FirstRun=0
[Hotkeys]
ToggleHotkey=Alt+Shift+F
NotifyHotkey=Ctrl+Shift+Alt+X
ToTraditionalHotkey=Alt+Shift+T
ToSimplifiedHotkey=Alt+Shift+S
[Convert]
UseTaiwanPhrases=0
```

| 設定 | 說明 |
|---|---|
| `Notify` | `1` 顯示切換提示，`0` 不顯示（也可以按 `Ctrl+Shift+Alt+X` 切換） |
| `ToggleHotkey` | 切換注音繁簡輸出的快速鍵 |
| `ToTraditionalHotkey`／`ToSimplifiedHotkey` | 選取文字轉繁／轉簡的快速鍵 |
| `UseTaiwanPhrases` | `1` 開啟台灣用語，`0` 只轉字形 |

**快速鍵格式：** 修飾鍵（`Ctrl`、`Alt`、`Shift`、`Win`）加上一個按鍵，用 `+` 連接。例如 `Ctrl+Alt+F`、`Win+Shift+Z`、`Ctrl+Alt+F9`。

**改完之後：** 存檔，再到右鍵選單點 **重新載入設定**。

> - 不要在數值後面加註解。
> - 快速鍵寫錯，或已經被其他程式占用時，程式會跳出提示，並改用預設值。

## 8. 常見問題

**Q：按 `Alt+Shift+F` 之後，輸入法跑掉或切到英文？**
`Alt+Shift` 是 Windows 預設的「切換輸入語言」快速鍵，少數情況下會被觸發。可以在設定檔把 `ToggleHotkey` 改成 `Ctrl+Alt+F` 這類組合。

**Q：切換之後，注音打出來還是一樣？**
先按 `Win + Space` 切到其他輸入法再切回注音，或切換到別的視窗再回來。這個功能只對「微軟注音」有效，其他注音輸入法（例如新酷音）不適用。

**Q：選取文字轉換沒有反應？**
- 確認文字真的有被選取（反白）。
- 部分程式不支援 `Ctrl+C`／`Ctrl+V`，或是以系統管理員身分執行，這時候無法轉換。
- 查看紀錄檔 `%APPDATA%\ImeSwitcher\log.txt`，裡面有每一步的記錄。

**Q：為什麼 `台湾` 轉成了 `臺灣`？**
台灣教育部的標準字形是「臺」，OpenCC 的台灣模式依照這個標準。

**Q：極少數罕用字轉換後沒變？**
例如「樠、蹻、殢」這類極罕用字，在繁轉簡時會刻意保持原字，因為它們的簡體字形在大多數字型裡顯示不出來，會變成方框。

**Q：程式會連網、收集資料嗎？**
不會。程式完全離線執行，不連網、不收集任何資料。程式修改的位置都列在 [README 的「程式會修改的東西」](../README.md#程式會修改的東西)。

**Q：執行時間久了，記憶體大約佔多少？**
大約 50–60MB，主要是轉換詞庫。

## 9. 移除程式

這個程式不用安裝，所以也不用解除安裝，照下面步驟清乾淨即可：

1. 如果有勾選「開機自動啟動」，先右鍵系統匣圖示**取消勾選**。
2. 右鍵系統匣圖示 → **結束**。
3. 刪除 `ImeSwitcher.exe`。
4. 刪除 `%APPDATA%\ImeSwitcher` 資料夾（設定檔與紀錄檔）。
5. 如果最後停在簡體輸出：在工作列的輸入法圖示（「中」或「英」）上按右鍵 → **設定** → **一般**，關閉 **輸出簡體中文**。
